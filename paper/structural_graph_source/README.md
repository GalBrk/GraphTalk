# Talk Like a Structured Graph — source package

The PDF uses the ACL 2023 proceedings style. Compile with:

```sh
pdflatex structured_graph.tex
bibtex structured_graph
pdflatex structured_graph.tex
pdflatex structured_graph.tex
```

The source results are in `GalBrk/GraphTalk`, branch `results-sot`, commit
`292046fbe23904109afbdca221b72224f30d0445`. The tagged sections of
`docs/results/n40-sweep.md` and `docs/results/density-followups.md` map to
LaTeX comments adjacent to the reported numbers. Figure 1 is regenerated by
`python plot_outcomes.py`; its outcomes come from the `[edgecount]` block of
`csv2/raw-trends/primer_findings.txt`. References start after five body pages;
the audit and complete paired comparison matrix follow the references.

The supplemental all-response set-F1 tests and edge-existence metric table
come from `metric_audit.py` applied to the repo's generated frame:

```sh
python metric_audit.py --frame /path/to/GraphTalk/csv2/raw-trends/frame.csv
```

Its reproducible output is included as `metric_audit.txt`. The F1 analysis
uses 50,000 seeded paired random-sign draws and adjusts each model arm's six
primer contrasts with Benjamini--Hochberg. These calculations use recorded
responses; they did not run new models.

Run primary_metric_tables.py after the metric audit to recreate
primary_metric_tables.tex. Appendix A reports all four arms' primary
connected-nodes Set-F1 comparisons and raw accuracy, balanced accuracy,
finished-response yes-rate, and truncation for the main-sweep edge-existence
conditions. Balanced accuracy and yes-rate comparisons are descriptive.
The [metric-audit-edge-errors] block also checks the paper's matched
false-positive and true-positive counts against the recorded responses.
Appendix B contains pilot provenance and focused robustness checks.

The full matrix is reconstructed from the recorded main-sweep frame and
cross-checked against all 144 contrasts in the tagged `[main]` report:

```sh
python matrix_audit.py \
  --frame /path/to/GraphTalk/csv2/raw-trends/frame.csv \
  --report /path/to/GraphTalk/csv2/raw-trends/primer_findings.txt \
  --output main_matrix.tex
```

The density discussion draws on the repository's recorded, fixed-40-node
density follow-ups; its uncorrected per-level contrasts are labeled
exploratory in the paper. No new model inference was performed.

The final revision adds focused interaction and bundle audits from the saved
responses:

```sh
python robustness_audit.py --repo /path/to/GraphTalk > robustness_audit.txt
```

`[interaction]` applies BH within three exploratory density interactions;
`[bundle-direct]` applies BH within six paired high-density alternatives.
Both use correct share of *all* graph prompts, with truncation retained as its
own outcome. The paper's pilot/model/size provenance is taken from the current
`docs/results/README.md` index: the earlier 20/40/80-node size analysis is
listed as unverified there, and is not used for a numerical performance claim.
