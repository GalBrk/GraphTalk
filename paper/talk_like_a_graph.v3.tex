\begin{abstract}
Prepending a primer of structural facts, such as each node's degree, is a
natural aid for a language model answering questions about a graph given as
text. We ask when such primers help, and why. We evaluate Qwen3-1.7B and
Qwen3-4B, with and without thinking, on six GraphQA tasks over 40-node
Erd\H{o}s--R\'enyi graphs (84,000 generations). A solver that never sees the
edges separates primers that state the answer from primers that supply side
information. On node-degree queries, a primer that states the answer adds
about 16 points where accuracy without it lies between 0.25 and 0.75, and it
costs Qwen3-4B accuracy where that model is already correct. The responses
indicate why: the primer changes the model's procedure. Qwen3-4B mostly
retrieves the stated degree instead of counting; it gains 27 points where its
count fails and loses 12 where its count is 99\% accurate. With thinking,
Qwen3-1.7B instead checks its count against the stated degree and gains 20
points. On edge queries, primers act on false ``yes'' answers: for Qwen3-1.7B,
the combined primer lowers the false-alarm rate by 19 points, and a preamble
that only restates the node set raises it by 18. Primer length has no
consistent effect.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

\citet{fatemi2023talklikeagraph} show that the accuracy of a large language
model (LLM) on graph questions depends strongly on how the graph is written as
text. A natural next step is to add derived structure to that text. We study
\emph{primers}: short preambles, placed before the graph encoding, that state
each node's degree, clustering coefficient or random-walk return probability,
or the graph's number of connected components. Graph neural networks take
these statistics as input features \citep{dwivedi2022graph,rampasek2022recipe};
here a pretrained LLM reads them as sentences.

Our research question is how primers change an LLM's answers on graph tasks,
and when they help rather than harm. We divide it into three parts.
\textbf{RQ1}: how much of a primer's effect comes from stating the answer, and
how much from side information that does not determine it? \textbf{RQ2}: what
decides whether a primer helps or harms a given model on a given task?
\textbf{RQ3}: what does a primer change in the procedure the model follows?

Two controls make these questions answerable. A graph-blind solver reads the
primer but never the edge list; where it is correct, the primer states the
answer (\emph{answer leakage}), and a gain may reflect retrieval rather than
reasoning \citep{geirhos2020shortcut}. Because added text can itself degrade
reasoning \citep{shi2023distracted,levy2024sametask}, a preamble that only
restates the node set and primers of $37$ to $4{,}691$ characters test whether
added text alone changes accuracy. We apply both controls to $84{,}000$
generations and analyse the responses as well as their scores.

The results suggest one account (Section~\ref{sec:discussion}): a primer that
states the answer changes the procedure the model follows, and its effect
depends on how accurate the new procedure is relative to the count it
replaces. The account covers three observations: on \texttt{node\_degree} such
effects follow the accuracy without a primer (Section~\ref{sec:results-window}),
one primer both helps and harms the same model on the same task
(Section~\ref{sec:results-procedure}), and a stated answer helps only a model
that can execute the procedure it implies (Section~\ref{sec:results-execute}).
On edge queries,
side information instead changes how often the model answers ``yes''
(Section~\ref{sec:results-side}).

\section{Related Work}
\label{sec:related}

GraphQA \citep{fatemi2023talklikeagraph}, NLGraph \citep{wang2023nlgraph},
GPT4Graph \citep{guo2023gpt4graph} and GraphArena \citep{tang2025grapharena}
evaluate LLMs on graph problems and vary the encoding, the prompt and the
task. \citet{sanford2024understanding} show that four of our six tasks can be
solved by a single transformer layer, yet prompted LLMs trail trained
transformers on them. Structure has been added to the input as an instruction
to build the graph first \citep{wang2023nlgraph}, as motif statistics
\citep{das2024modality} and as learned soft tokens
\citep{perozzi2024letyourgraph}. \citet{huang2024can} find that such text helps
node classification through label-relevant phrases rather than through
structure. We make the analogous separation for every task and condition,
between text that determines the answer and text that does not. In the
taxonomy of \citet{rampasek2022recipe}, our primers state local structural
encodings (degree, triangle-based clustering and random-walk return
probability; \citealp{dwivedi2022graph}) and one global encoding, the number
of components.

The graph-blind solver is a partial-input baseline, as hypothesis-only models
are for natural language inference
\citep{gururangan2018annotation,poliak2018hypothesis}, applied here to an
intervention rather than to a dataset. Accuracy also depends on where
information sits in the context \citep{liu2024lostinthemiddle} and on the order
of a graph description \citep{ge2025graph}.

\section{Method}
\label{sec:method}

\subsection{Primers and the graph-blind solver}
\label{sec:primers}

\input{v3_conditions_table.tex}

A prompt consists of a primer, the graph in the \texttt{incident} encoding of
\citet{fatemi2023talklikeagraph}, and the question
(Appendix~\ref{sec:appendix-prompt}). Seven conditions share one renderer
(Table~\ref{tab:conditions}). The five \emph{content} primers state graph
statistics, one sentence per node in id order, except \texttt{components},
which is a single sentence. \texttt{filler} writes ``Node $i$ is simply present within the graph $G$'' for each node: it
restates the node set, which the encoding already lists, at a length $12\%$
above that of \texttt{clustering}.

The graph-blind solver reads the rendered primer and the graph's node and edge
counts, never the edge list. It applies exact rules where they exist and
heuristic or fitted rules otherwise (fitted on separate graphs), so its
accuracy is a lower bound on what the primer and the two counts determine. We
call a primer \emph{answer-carrying} on a task when the solver scores at least
$0.85$ there, and \emph{side information} otherwise. Any threshold between
$0.75$ and $1.00$ gives this split: on the four tasks whose gold answer
varies, \texttt{degree} and \texttt{all} score $1.00$ on \texttt{node\_degree}
and \texttt{edge\_count}, and every other primer scores at most $0.75$
(Appendix Table~\ref{tab:shortcut}).

\subsection{Corpus, models and measurement}
\label{sec:setup}

Graphs are Erd\H{o}s--R\'enyi $G(n,p)$ graphs
\citep{erdosrenyi1959random,gilbert1959random} with $n{=}40$ nodes at
$p\in\{.10,.20,.35,.50\}$, $100$ per density. The same graphs serve all six
GraphQA tasks, and \texttt{node\_degree}, \texttt{connected\_nodes} and
\texttt{edge\_existence} query the same node. \texttt{node\_degree} and
\texttt{edge\_existence} are extended to $p\in\{.65,.75,.85\}$. Four arms
answer every prompt: Qwen3-1.7B and Qwen3-4B \citep{qwen2025qwen3} with
thinking mode off (\texttt{qwen3-1.7b}, \texttt{qwen3-4b}) and on
(\texttt{-think}), $84{,}000$ generations. Decoding is greedy, with a budget of
$8{,}192$ new tokens ($2{,}048$ for the plain arms in the extension). For
\texttt{qwen3-1.7b} on \texttt{node\_degree} we use three further runs: $400$
graphs per density (the main sweep's $100$ and $300$ new), $1{,}600$ graphs drawn
with fresh seeds, and a grid that holds the mean degree at $8$ or $16$ while
$n$ ranges over $\{20,40,80,160\}$.

Every task is scored by exact match; on \texttt{connected\_nodes}, set-F1
moves about a sixth as much as exact match and reverses two of the five
contrasts larger than $5$ points. On
\texttt{edge\_existence} the share of queried pairs that are edges rises from
$10\%$ to $85\%$ with density, so we also report the hit rate (``yes'' to an
edge), the false-alarm rate (``yes'' to a non-edge) and balanced accuracy.
Each effect is a paired difference against \texttt{none} on the same graphs,
in percentage points. A pair is dropped when either generation reaches the
token budget (rates in Appendix Table~\ref{tab:hitcap}). A \emph{cell} is one
(arm, task, density, content primer) combination; we keep the $393$ cells that retain
at least $50$ pairs, and the $47$ dropped are \texttt{edge\_count} cells.
\texttt{node\_count} and \texttt{cycle\_check} have a constant gold answer at
$n{=}40$, so we exclude them from all summaries
(Appendix~\ref{sec:appendix-constgold}). Tests are exact McNemar
\citep{mcnemar1947note} with Benjamini--Hochberg correction
\citep{benjaminihochberg1995controlling} within each (arm, task), and
intervals are $95\%$ bootstrap intervals over graphs
\citep{efron1979bootstrap}.

\subsection{Primer effects follow baseline accuracy}
\label{sec:results-window}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{v3_fig_window.pdf}
\caption{Effect of each content primer against the cell's accuracy without it.
Triangles: answer-carrying; circles: side information; filled: $q<.05$ within
each (arm, task). The line joins the seven densities of \texttt{degree} for
\texttt{qwen3-4b} on \texttt{node\_degree}; shading marks baselines
$0.25$--$0.75$.}
\label{fig:window}
\end{figure}

Figure~\ref{fig:window} plots each cell's effect against its accuracy without
a primer, its \emph{baseline}. Answer-carrying primers gain most at
intermediate baselines: $+16.0$ and $+16.7$ points at baselines of
$0.25$--$0.50$ and $0.50$--$0.75$ (all $18$ such cells are
\texttt{node\_degree} cells), against $+7.8$ below $0.25$ and $-5.7$ between
$0.75$ and $0.90$. Above $0.90$ they cost $1.4$ points on average, and
every such cell of \texttt{qwen3-4b} loses accuracy ($-1$ to $-15$). Side
information follows the same shape at a smaller scale: $+2.3$ and $+3.9$ in the
two middle bands, $-1.8$ below $0.25$ and $-0.8$ above $0.90$. The pattern is
not regression to the mean: binning each cell on half its graphs and
measuring the effect on the other half reproduces every band to within about
$3$ points.

Thinking raises the median baseline from $59.0$ to $94.9$ on the 1.7B model
and from $87.0$ to $100.0$ on the 4B model. It empties the range below $0.25$,
which holds $28$ and $20$ cells without thinking, and leaves the 1.7B model a
similar share between $0.25$ and $0.75$ ($40$ of $103$ cells, then $35$ of
$90$) but the 4B model none ($10$ of $110$ before). Pooled over $p\le.50$, no
primer moves \texttt{qwen3-4b-think} by more than $2.1$ points on
\texttt{node\_degree}, \texttt{edge\_existence} or \texttt{connected\_nodes}
(Table~\ref{tab:main}).

Table~\ref{tab:main} breaks the effects down by task. Answer-carrying primers
raise \texttt{node\_degree} on both 1.7B arms ($+7.5$ to $+11.7$) and lower it
on \texttt{qwen3-4b} ($-6.5$, $-8.0$), and \texttt{degree} raises
\texttt{qwen3-4b} on \texttt{edge\_count} by $27.7$. As side information,
\texttt{all} helps \texttt{qwen3-1.7b} on \texttt{edge\_existence} ($+11.5$),
\texttt{clustering} is the only primer that helps \texttt{qwen3-4b} there
($+4.0$), and \texttt{filler} produces the largest costs ($-15.7$, $-12.5$).

\subsection{The sign follows the procedure the primer replaces}
\label{sec:results-procedure}

For \texttt{qwen3-4b} on \texttt{node\_degree}, the \texttt{degree} primer
states the queried degree and changes accuracy by $-6$, $-1$, $-7$ and $-12$
points at $p{=}.10$ to $.50$, by $-6$ at $.65$, by $+7$ at $.75$ and by $+27$ at
$.85$ (Figure~\ref{fig:window}, line). The losses are not a cost of added text:
at $p{=}.50$ the primer turns $13$ correct answers into errors and corrects
one, no generation truncates, and \texttt{filler}, which is longer, costs $2$
points.

The responses show a change of procedure. We classify a \texttt{node\_degree}
response as \emph{retrieval} when it states its answer before restating the
queried node's neighbour list, or without restating it, and as
\emph{enumeration} when it lists the neighbours one per line (Appendix
Table~\ref{tab:routes}). Without a primer there is no stated degree to
retrieve, so the baseline of \texttt{qwen3-4b} is the accuracy of its own
count: $99$--$100\%$ up to $p{=}.50$, then $82\%$, $50\%$ and $33\%$. Under
\texttt{degree} it retrieves in $47$--$97\%$ of responses, at $57$--$97\%$
accuracy. Retrieval is less accurate than the count up to $p{=}.65$ and more
accurate at $.75$ and $.85$, which matches the sign of the effect at all seven
densities. Enumeration falls from $85$--$100\%$ of responses to at most $8\%$
at $p{=}.35$ to $.75$. Under \texttt{all}, which states the degree among two
other statistics, the model retrieves in $27$--$86\%$ of responses at
$40$--$94\%$ accuracy, its other responses are $43\%$, $4\%$ and $2\%$
accurate from $p{=}.65$, and the primer lowers accuracy at every density, by
up to $37$ points.

The thinking arm uses the same primer differently: under \texttt{degree},
\texttt{qwen3-1.7b-think} retrieves in at most $2\%$ of responses and, from
$p{=}.35$ on, enumerates the neighbours in $76$--$98\%$. It reports a discrepancy between its count and the primer in
$26\%$ of responses up to $p{=}.50$ and in $49\%$ beyond, whereas without a
primer $1\%$ and $4\%$ of responses report any discrepancy, and it answers
correctly in about two thirds of the responses that report one. The primer
adds $19.9$ points $[16.3, 23.6]$ over the seven densities and $31.6$ points
above $p{=}.50$, without the loss at
high baselines ($+5.2$ and $-1.0$ at $p{=}.10$ and $.20$).
\texttt{qwen3-1.7b}, finally, rarely retrieves (at most $4\%$ of responses),
yet gains $10$ and $18$ points at $p{=}.20$ and $.35$, where its count is
partly right ($80\%$ and $41\%$), and stays within $2$ points from $p{=}.50$,
where its baseline is $5$--$30\%$.

\subsection{A stated answer helps only through a procedure the model can
execute}
\label{sec:results-execute}

On \texttt{edge\_count}, \texttt{degree} states every degree, so the answer
is half their sum. Without a primer \texttt{qwen3-4b} already sets out to sum
the degrees ($96$--$100\%$ of responses) but is exact on only $2\%$ of graphs.
Given the degrees it is exact on $30\%$ of graphs: $+23$, $+30$, $+24$ and
$+34$ points across the four densities, with $114$ items corrected and $5$
broken. \texttt{qwen3-1.7b} takes up the same procedure (from $7$--$67\%$ of
responses to $99$--$100\%$) but rarely completes the forty-term sum correctly:
$4.7\%$ of its answers are exact, a gain of $4.0$ points that does not survive
correction, although its mean absolute error falls from $136$ to $40$ edges.

\subsection{Side information shifts false alarms and helps where counting
fails}
\label{sec:results-side}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{v3_fig_edgeexist.pdf}
\caption{\texttt{qwen3-1.7b} on \texttt{edge\_existence}: (a) balanced
accuracy and (b) median new tokens by density. Without a primer the model
answers ``yes'' to almost every pair from $p{=}.65$; under \texttt{filler},
from $p{=}.35$.}
\label{fig:edgeexist}
\end{figure}

On \texttt{edge\_existence} the plain arms answer ``yes'' to $97$--$100\%$ of
true edges under every condition, and $94$--$99\%$ of their errors are false
alarms, so primers change accuracy almost entirely through the false-alarm
rate. Pooled
over the seven densities, \texttt{all} lowers the false-alarm rate of
\texttt{qwen3-1.7b} from $0.51$ to $0.33$ ($-18.6$ points $[-24.0, -13.1]$),
and \texttt{degree}, \texttt{rwse} and \texttt{clustering} lower it by $6$ to
$9$ points; \texttt{filler} raises it to $0.69$ ($+18.3$ $[13.9, 22.7]$) and
\texttt{components} to $0.61$. For \texttt{qwen3-4b}, \texttt{clustering} is
the only primer that lowers the false-alarm rate ($0.16$ to $0.08$) and the
only one that raises accuracy on the task ($+4.6$ $[2.3, 6.9]$); the other
five conditions raise false alarms by $7$ to $14$ points.

At high density \texttt{qwen3-1.7b} defaults to ``yes''
(Figure~\ref{fig:edgeexist}). Without a primer it answers ``yes'' to
$98$--$99\%$ of pairs from $p{=}.65$, in median responses of $48$--$120$ tokens,
at a balanced accuracy of $0.52$--$0.53$. Primers that state per-node values
keep the responses at $259$--$404$ tokens, and the two that state degrees
restore part of the balanced accuracy (\texttt{degree} $+9.5$ $[4.5, 15.0]$,
\texttt{all} $+14.9$ $[8.7, 21.4]$). \texttt{filler} brings the default forward
to $p{=}.35$, where the model answers ``yes'' to $97\%$ of pairs against $65\%$
without a primer.

Side information also helps where counting fails. On \texttt{node\_degree}
above $p{=}.50$, where \texttt{qwen3-4b} counts correctly on $33$--$82\%$ of
items, \texttt{clustering} adds $11.3$ points $[6.7, 16.3]$ ($46$ items
corrected, $12$ broken) and \texttt{rwse} adds $7.7$, whereas \texttt{filler}
adds $2.0$ (not significant). These primers state no degree, so the answer
still comes from the model's own count, and at these densities the printed
coefficients barely vary within a graph (standard deviation at most $0.02$),
so the gain does not rest on node-specific values. The solver
scores \texttt{clustering} as it scores \texttt{none}, yet the primer also
helps \texttt{qwen3-1.7b}: its gain of $+3.0$ in the main sweep replicates in
the three dedicated runs, at $+4.0$, $+4.2$ and $+6.2$ points on the $300$ new
graphs per density, the fresh seeds and the fixed-degree grid ($p\le.005$ in
each).

Some gains need no graph-specific content: \texttt{components} raises
\texttt{qwen3-4b} on \texttt{connected\_nodes} by $9$ to $11$ points at
$p\ge.20$, where every graph is connected and the primer is the same
$37$-character sentence for all of them, and by $+7$ at $p{=}.10$, where it
varies.

\subsection{No consistent gain from bundling or length}
\label{sec:results-bundle}

\texttt{all} states every value that \texttt{degree}, \texttt{clustering} and
\texttt{rwse} state, yet its effect exceeds the mean of theirs by only $0.2$
points on average ($[-1.1, 1.6]$ over $54$ (arm, task, density)
combinations). It can
also lose what each part gains: on \texttt{qwen3-4b}/\texttt{node\_degree}
above $p{=}.50$, \texttt{degree}, \texttt{clustering} and \texttt{rwse} add
$9.3$, $11.3$ and $7.7$ points, whereas \texttt{all} costs $21.3$
(Section~\ref{sec:results-procedure}).

Primer length does not order the effects consistently. Regressing each (arm,
task)'s effects on the lengths of the five content primers gives slopes from
$-6.5$ to $+3.4$ points per $1{,}000$ characters, positive in $7$ of $8$ fits
for the 1.7B model and in none of $8$ for the 4B model; without \texttt{all},
the longest primer, $3$ and $1$ of $8$ are positive. \texttt{filler} lies
$18.3$ and $13.8$ points below the fitted line where it harms most. On
\texttt{node\_count}, which the summaries exclude, \texttt{qwen3-1.7b} answers
$39$ instead of $40$ on $68.5\%$ of items without a primer, $1.2\%$ under
\texttt{clustering} and $66.5\%$ under the longer \texttt{rwse} (Appendix
Table~\ref{tab:constgold}).

\section{Discussion and Conclusion}
\label{sec:discussion}

The results suggest one account. A primer that states the answer changes the
procedure the model follows, and its effect depends on how accurate the new
procedure is relative to the count it replaces. Without a primer the model
must count, so its baseline measures the count a primer can displace, which is
why these effects follow it. For \texttt{qwen3-4b} the new procedure is
retrieval, which beats its count only from $p{=}.75$; \texttt{all} makes
retrieval less accurate and its other responses fail at high density, so it
loses even where its parts help. The 1.7B arms keep counting, and the thinking
arm uses the primer as a check. A new procedure must also be executable: given
every degree, \texttt{qwen3-4b} completes the sum exactly on $30\%$ of graphs
and \texttt{qwen3-1.7b} on $5\%$, a failure of multi-step composition of the
kind \citet{dziri2023faithandfate} describe. Side information that does not state
the answer acts on another channel: on edge queries it changes how often the
model answers ``yes''.

Two results bear on prior work. A single transformer layer can solve
\texttt{node\_degree} and \texttt{edge\_count}
\citep{sanford2024understanding}, the two tasks on which a primer states the
answer, yet given the answer \texttt{qwen3-4b} is right on $87\%$ of
\texttt{node\_degree} items at $p{=}.50$ and on $30\%$ of \texttt{edge\_count}
graphs: for a prompted model the difficulty appears to lie in the procedure,
not in the information. Added text acts through what it states: restating the
node set raises false ``yes'' answers, consistent with the distraction
\citet{shi2023distracted} report, while the length slopes change sign between
models, unlike the consistent cost \citet{levy2024sametask} report.

In answer to our questions: on \texttt{node\_degree} a stated answer is worth
about $16$ points at intermediate baselines, and side information $2$ to $4$
points across tasks (RQ1); the sign of a stated answer's effect follows the
accuracy of the count the primer displaces (RQ2); and a primer changes the
model's procedure, to retrieval or verification on \texttt{node\_degree} and,
on edge queries, to a different rate of ``yes'' answers (RQ3). Evaluations of graph prompts should
report each cell's baseline accuracy, a graph-blind solver's score and, for
yes/no tasks, the false-alarm rate.

\section*{Limitations}
\label{sec:limitations}

We evaluate two model sizes from one family, with one encoding, template and
primer position. Decoding is greedy, whereas the Qwen3 model card
\citep{qwen2025qwen3card} recommends sampling in thinking mode, so the thinking arms' truncation on
\texttt{edge\_count} ($81\%$ and $62\%$) may be specific to this protocol. A
cell of $100$ graphs detects paired effects of about $8$ points, so the
side-information results rest on averages over cells. Procedures are
classified by surface patterns, and a model may follow a procedure it does not
state. The length comparison varies length only across primers whose content
also differs.

This work evaluates open-weight models on synthetic graphs, with no human
subjects, personal data or annotation. Its main cost is GPU compute: about
$217{,}000$ generations over the project, $98{,}400$ of them analysed here.%
