\begin{abstract}
Prepending a primer of structural facts, such as each node's degree, is a
natural aid for a language model that answers questions about a graph given
as text. We ask when such primers help, and why. Across 84,000 generations
from Qwen3-1.7B and Qwen3-4B, with and without thinking, on six GraphQA
tasks over 40-node Erd\H{o}s--R\'enyi graphs, a solver that never sees the
edges separates primers that state the answer from primers that supply side
information. A primer that states the answer adds about 16 points where
accuracy without it lies between 0.25 and 0.75, and it costs accuracy where
the model is already correct. The responses show why: the model uses the
primer as an alternative procedure. Qwen3-4B reads the stated degree instead
of counting; it gains 27 points where its count fails and loses 12 where its
count is 99\% accurate. With thinking enabled, Qwen3-1.7B instead checks its
count against the stated degree and gains 20 points. Side information acts
mainly on false ``yes'' answers to edge queries: for Qwen3-1.7B, the richest
primer removes 19 points of them, and a preamble that only restates the node
set adds 18. Primer length does not order these effects.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

\citet{fatemi2023talklikeagraph} show that the accuracy of a large language
model (LLM) on graph questions depends strongly on how the graph is written as
text. A natural next step is to add derived structure to that text. We study
\emph{primers}: short preambles, placed before the graph encoding, that state
each node's degree, clustering coefficient or random-walk return probability,
or the graph's number of connected components. Graph neural networks take
these statistics as input features \citep{dwivedi2022graph,rampasek2022recipe};
here a pretrained LLM reads them as sentences.

Our research question is how primers change an LLM's answers on graph tasks,
and when they help rather than harm. We divide it into three parts.
\textbf{RQ1}: how much of a primer's effect comes from stating the answer, and
how much from side information that does not determine it? \textbf{RQ2}: what
decides whether a primer helps or harms a given model on a given task?
\textbf{RQ3}: what does a primer change in the procedure the model follows?

Two controls make these questions answerable. A graph-blind solver reads the
primer but never the edge list; where it is correct, the primer states the
answer, and a gain may reflect retrieval rather than reasoning
\citep{geirhos2020shortcut}. A preamble that only restates the node set,
together with primers of $37$ to $4{,}691$ characters, separates content from
added text \citep{shi2023distracted,levy2024sametask}. We apply both controls
to $84{,}000$ generations and analyse the responses as well as their scores.

The results support one account (Section~\ref{sec:discussion}): a primer
offers the model an alternative procedure, and its effect is the accuracy of
the procedure the model adopts minus that of the one it abandons. This
explains why effects follow the model's accuracy without a primer
(Section~\ref{sec:results-window}), why one primer helps and harms the same
model on the same task (Section~\ref{sec:results-procedure}), and why a stated
answer helps only a model that can use it (Section~\ref{sec:results-execute}).
On edge queries, side information instead changes how often the model answers
``yes'' (Section~\ref{sec:results-side}).

\section{Related Work}
\label{sec:related}

GraphQA \citep{fatemi2023talklikeagraph}, NLGraph \citep{wang2023nlgraph},
GPT4Graph \citep{guo2023gpt4graph} and GraphArena \citep{tang2025grapharena}
evaluate LLMs on graph problems and vary the encoding, the prompt and the
task. \citet{sanford2024understanding} show that four of our six tasks can be
solved by a single transformer layer, yet prompted LLMs trail trained
transformers on them. Structure has been added to the input as an instruction
to build the graph first \citep{wang2023nlgraph}, as motif statistics
\citep{das2024modality} and as learned soft tokens
\citep{perozzi2024letyourgraph}. \citet{huang2024can} find that such text helps
node classification through label-relevant phrases rather than through
structure. These studies report gains without separating text that determines
the answer from text that does not; we make that separation for every task and
condition. Our primers render, as sentences, structural encodings that graph
networks use as input features: in the taxonomy of \citet{rampasek2022recipe},
degree, triangle-based clustering and random-walk return probability
\citep{dwivedi2022graph} are local encodings, and the number of components is
global.

The graph-blind solver is a partial-input baseline, as hypothesis-only models
are for natural language inference
\citep{gururangan2018annotation,poliak2018hypothesis}, applied here to an
intervention rather than to a dataset. Added text can degrade reasoning
\citep{shi2023distracted,levy2024sametask}, and accuracy depends on where
information sits in the context \citep{liu2024lostinthemiddle} and on the order
of a graph description \citep{ge2025graph}.

\section{Method}
\label{sec:method}

\subsection{Primers and the graph-blind solver}
\label{sec:primers}

\input{v3_conditions_table.tex}

A prompt consists of a primer, the graph in the \texttt{incident} encoding of
\citet{fatemi2023talklikeagraph}, and the question
(Appendix~\ref{sec:appendix-prompt}). Seven conditions share one renderer
(Table~\ref{tab:conditions}). The primers write one sentence per node in id
order, except \texttt{components}, which is a single sentence. \texttt{filler}
writes ``Node $i$ is simply present within the graph $G$'' for each node: it
restates the node set, which the encoding already lists, at a length within
$12\%$ of that of \texttt{clustering}.

The graph-blind solver reads the rendered primer and the graph's node and edge
counts, never the edge list. It applies exact rules where they exist and
heuristic or fitted rules otherwise (fitted on separate graphs), so its
accuracy is a lower bound on what the primer alone determines. We call a primer \emph{answer-carrying} on a task
when the solver scores at least $0.85$ there, and \emph{side information}
otherwise. The threshold does not matter: on the four tasks whose gold answer
varies, \texttt{degree} and \texttt{all} score $1.00$ on \texttt{node\_degree}
and \texttt{edge\_count}, and every other primer scores at most $0.75$
(Appendix Table~\ref{tab:shortcut}).

\subsection{Corpus, models and measurement}
\label{sec:setup}

Graphs are Erd\H{o}s--R\'enyi $G(n,p)$ graphs
\citep{erdosrenyi1959random,gilbert1959random} with $n{=}40$ nodes at
$p\in\{.10,.20,.35,.50\}$, $100$ per density. The same graphs serve all six
GraphQA tasks, and \texttt{node\_degree}, \texttt{connected\_nodes} and
\texttt{edge\_existence} query the same node. \texttt{node\_degree} and
\texttt{edge\_existence} are extended to $p\in\{.65,.75,.85\}$. Four arms
answer every prompt: Qwen3-1.7B and Qwen3-4B \citep{qwen2025qwen3} with
thinking mode off (\texttt{qwen3-1.7b}, \texttt{qwen3-4b}) and on
(\texttt{-think}), $84{,}000$ generations in total. Decoding is greedy, with a
budget of $8{,}192$ new tokens ($2{,}048$ for the plain arms in the
extension). For \texttt{qwen3-1.7b} on \texttt{node\_degree} we use three
further runs: $400$ graphs per density, $1{,}600$ graphs drawn with fresh
seeds, and a grid that holds the mean degree at $8$ or $16$ while $n$ ranges
over $\{20,40,80,160\}$.

Every task is scored by exact match; on \texttt{connected\_nodes}, set-F1
would compress the contrasts about sixfold. On
\texttt{edge\_existence} the share of queried pairs that are edges rises from
$10\%$ to $85\%$ with density, so we also report the hit rate (``yes'' to an
edge), the false-alarm rate (``yes'' to a non-edge) and balanced accuracy.
Each effect is a paired difference against \texttt{none} on the same graphs,
in percentage points. A pair is dropped when either generation reaches the
token budget (rates in Appendix Table~\ref{tab:hitcap}). A \emph{cell} is one
(arm, task, density, primer) combination; we keep the $393$ cells that retain
at least $50$ pairs, and the $47$ dropped are \texttt{edge\_count} cells.
\texttt{node\_count} and \texttt{cycle\_check} have a constant gold answer at
$n{=}40$, so we exclude them from all summaries
(Appendix~\ref{sec:appendix-constgold}). Tests are exact McNemar
\citep{mcnemar1947note} with Benjamini--Hochberg correction
\citep{benjaminihochberg1995controlling} within each (arm, task), and
intervals are $95\%$ bootstrap intervals over graphs
\citep{efron1979bootstrap}. All but one of the $78{,}538$ generations that
terminate yield an answer.

\subsection{Primer effects follow baseline accuracy}
\label{sec:results-window}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{v3_fig_window.pdf}
\caption{Effect of each primer against the cell's accuracy without it.
Triangles: answer-carrying; circles: side information; filled: significant
after correction. The line joins the seven densities of \texttt{degree} for
\texttt{qwen3-4b} on \texttt{node\_degree}; shading marks baselines
$0.25$--$0.75$.}
\label{fig:window}
\end{figure}

Figure~\ref{fig:window} plots each cell's effect against its accuracy without
a primer, its \emph{baseline}. Answer-carrying primers gain most at
intermediate baselines: $+16.0$ and $+16.7$ points at baselines of
$0.25$--$0.50$ and $0.50$--$0.75$, against $+7.8$ below $0.25$ and $-5.7$
between $0.75$ and $0.90$. Above $0.90$ they cost $1.4$ points on average, and
every such cell of \texttt{qwen3-4b} loses accuracy ($-1$ to $-15$). Side
information follows the same shape at a smaller scale: $+2.3$ and $+3.9$ in the
two middle bands, $-1.8$ below $0.25$ and $-0.8$ above $0.90$. The pattern is
not regression to the mean: binning each cell on half its graphs and
measuring the effect on the other half reproduces every band to within $3$
points.

Thinking mode moves most cells out of this range. It raises the median
baseline from $59.0$ to $94.9$ on the 1.7B model and from $87.0$ to $100.0$ on
the 4B model, leaving $40$ of \texttt{qwen3-1.7b}'s $103$ cells between $0.25$
and $0.75$, $35$ of $90$ for \texttt{qwen3-1.7b-think}, $10$ of $110$ for
\texttt{qwen3-4b} and none for \texttt{qwen3-4b-think}, which no primer moves by
more than $2.1$ points on \texttt{node\_degree}, \texttt{edge\_existence} or
\texttt{connected\_nodes}.

Table~\ref{tab:main} breaks the effects down by task. Answer-carrying primers
raise \texttt{node\_degree} on both 1.7B arms ($+7.5$ to $+11.7$) and lower it
on \texttt{qwen3-4b} ($-6.5$, $-8.0$), and \texttt{degree} raises
\texttt{qwen3-4b} on \texttt{edge\_count} by $27.7$. As side information,
\texttt{all} helps \texttt{qwen3-1.7b} on \texttt{edge\_existence} ($+11.5$),
\texttt{clustering} is the only primer that helps \texttt{qwen3-4b} there
($+4.0$), and \texttt{filler} produces the largest costs ($-15.7$, $-12.5$).

\subsection{The sign follows the procedure the primer replaces}
\label{sec:results-procedure}

For \texttt{qwen3-4b} on \texttt{node\_degree}, the \texttt{degree} primer
states the queried degree and changes accuracy by $-6$, $-1$, $-7$ and $-12$
points at $p{=}.10$ to $.50$, by $-6$ at $.65$, by $+7$ at $.75$ and by $+27$ at
$.85$ (Figure~\ref{fig:window}, line). The losses are not a cost of added text:
at $p{=}.50$ the primer turns $13$ correct answers into errors and corrects
one, no generation truncates, and \texttt{filler}, which is longer, costs $2$
points.

The responses show a change of procedure. We classify a \texttt{node\_degree}
response as \emph{counting} when it restates the queried node's neighbour list
and as \emph{retrieval} when it gives the answer without doing so (Appendix
Table~\ref{tab:routes}). Without a primer \texttt{qwen3-4b} counts in
$98$--$100\%$ of responses, so its baseline is the accuracy of counting:
$99$--$100\%$ up to $p{=}.50$, and $50\%$ and $33\%$ at $p{=}.75$ and $.85$.
Under \texttt{degree} it retrieves in $44$--$74\%$ of responses, retrieval is
$73$--$98\%$ accurate at every density, and the median response shortens from
$273$ to $34$ tokens at $p{=}.50$. Retrieval is therefore less accurate than
counting up to $p{=}.50$ and more accurate at $p{=}.75$ and $.85$, which is
the sign of the effect at those densities. Under \texttt{all}, which states
the degree among two other statistics, the model retrieves less often
($16$--$51\%$) and less accurately ($49$--$96\%$), and the primer lowers
accuracy at every density, by up to $37$ points.

The thinking arm uses the same primer differently.
\texttt{qwen3-1.7b-think} almost never retrieves: from $p{=}.35$ on it still
enumerates the neighbours in $76$--$98\%$ of responses under \texttt{degree},
and it reports a discrepancy between its count and the primer in $26\%$ of
responses up to $p{=}.50$ and in $49\%$ beyond, against $1\%$ and $4\%$
without a primer, and resolves about two thirds of these discrepancies
correctly. The primer adds $19.9$ points $[16.3, 23.5]$ over the seven
densities ($156$ items corrected, $29$ broken) and $31.6$ points above
$p{=}.50$, without the loss at high baselines ($+5.2$ and $-1.0$ at $p{=}.10$
and $.20$). \texttt{qwen3-1.7b}, finally, rarely uses the stated value: it
retrieves in at most $4\%$ of responses, and from $p{=}.50$, where its
baseline is $5$--$30\%$, its accuracy under \texttt{degree} stays within $2$
points of its accuracy without a primer.

\subsection{A stated answer helps only through a procedure the model can
execute}
\label{sec:results-execute}

On \texttt{edge\_count}, \texttt{degree} states every degree, so the answer
is half their sum. \texttt{qwen3-4b}
already describes this route without a primer ($96$--$100\%$ of responses) but
is exact on only $2\%$ of graphs. Given the degrees it is exact on $30\%$ of
graphs: $+23$, $+30$, $+24$ and $+34$ points across the four densities, with
$114$ items corrected and $5$ broken. \texttt{qwen3-1.7b} adopts the route
(from $7$--$67\%$ of responses to $99$--$100\%$) but rarely completes the
forty-term sum correctly: $4.7\%$ of its answers are exact, a gain of $4.0$ points that
does not survive correction, although its mean absolute error falls from $136$
to $40$ edges. Where the primer states the answer outright, accuracy under it
measures how much of the answer each arm takes up: on \texttt{node\_degree}
$0.99$, $0.86$, $0.81$ and $0.43$ for \texttt{qwen3-4b-think},
\texttt{qwen3-1.7b-think}, \texttt{qwen3-4b} and \texttt{qwen3-1.7b}, against
$0.99$, $0.66$, $0.80$ and $0.39$ without it.

\subsection{Side information shifts false alarms and helps where counting
fails}
\label{sec:results-side}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{v3_fig_edgeexist.pdf}
\caption{\texttt{qwen3-1.7b} on \texttt{edge\_existence}: (a) balanced
accuracy and (b) median new tokens by density. Without a primer the model
answers ``yes'' to almost every pair from $p{=}.65$; under \texttt{filler},
from $p{=}.35$.}
\label{fig:edgeexist}
\end{figure}

On \texttt{edge\_existence} the plain arms answer ``yes'' to $97$--$100\%$ of
true edges under every condition, and $94$--$99\%$ of their errors are false
alarms, so primers change accuracy through the false-alarm rate alone. Pooled
over the seven densities, \texttt{all} lowers the false-alarm rate of
\texttt{qwen3-1.7b} from $0.51$ to $0.33$ ($-18.6$ points $[-24.0, -13.1]$),
and \texttt{degree}, \texttt{rwse} and \texttt{clustering} lower it by $6$ to
$9$ points; \texttt{filler} raises it to $0.69$ ($+18.3$ $[14.2, 22.7]$) and
\texttt{components} to $0.61$. For \texttt{qwen3-4b}, \texttt{clustering} is
the only primer that lowers the false-alarm rate ($0.16$ to $0.08$) and the
only one that raises accuracy on the task ($+4.6$ $[2.0, 6.9]$); the other
five conditions raise false alarms by $7$ to $14$ points.

At high density \texttt{qwen3-1.7b} defaults to ``yes''
(Figure~\ref{fig:edgeexist}). Without a primer it answers ``yes'' to
$98$--$99\%$ of pairs from $p{=}.65$, in median responses of $48$--$120$ tokens,
at a balanced accuracy of $0.52$--$0.53$. Primers that state per-node values
keep the responses at $259$--$404$ tokens, and the two that state degrees
restore part of the balanced accuracy (\texttt{degree} $+9.5$ $[4.7, 15.3]$,
\texttt{all} $+14.9$ $[8.4, 21.5]$). \texttt{filler} brings the default forward
to $p{=}.35$, where the model answers ``yes'' to $97\%$ of pairs against $65\%$
without a primer.

Side information also helps where counting fails. On \texttt{node\_degree}
above $p{=}.50$, where \texttt{qwen3-4b} counts correctly on $33$--$82\%$ of
items, \texttt{clustering} adds $11.3$ points $[6.3, 16.0]$ ($46$ items
corrected, $12$ broken) and \texttt{rwse} adds $7.7$, whereas \texttt{filler}
adds $2.0$ (not significant). These primers state no degree, and the model
keeps counting under them. For \texttt{qwen3-1.7b} the \texttt{clustering}
gain replicates on the dedicated runs: $+3.8$ points $[1.4, 6.1]$ at $400$
graphs per density, $+4.2$ $[2.0, 6.6]$ on $1{,}600$ fresh graphs and $+6.2$
$[4.5, 8.0]$ across the $3{,}191$ items of the fixed-degree grid ($p\le.002$
in each), consistent with the $+3.0$ of the main sweep; its solver score
equals that of \texttt{none}, so this gain is not leakage.

Some gains need no graph-specific content: \texttt{components} raises
\texttt{qwen3-4b} on \texttt{connected\_nodes} by $+9$ to $+11$ points at
$p\ge.20$, where every graph is connected and the primer is the same
$37$-character sentence for all of them, and by $+7$ at $p{=}.10$, where it
varies.

\subsection{Bundling and length}
\label{sec:results-bundle}

\texttt{all} states every value that \texttt{degree}, \texttt{clustering} and
\texttt{rwse} state, yet its effect is close to the mean of theirs ($+0.2$
points $[-1.1, 1.5]$ over $54$ cells) and $4.6$ points $[2.5, 6.8]$ below the
best of them. Where the
model must retrieve one value among three, the bundle loses what its parts
gain: on \texttt{qwen3-4b}/\texttt{node\_degree} above $p{=}.50$,
\texttt{degree}, \texttt{clustering} and \texttt{rwse} add $9.3$, $11.3$ and
$7.7$ points, whereas \texttt{all} costs $21.3$.

Primer length does not order the effects. Regressing each (arm, task)'s
effects on the lengths of the five content primers gives slopes from $-6.5$ to
$+3.4$ points per $1{,}000$ characters, positive in $7$ of $8$ fits for the 1.7B
model and in none of $8$ for the 4B model, and \texttt{filler} lies $18.3$ and
$13.8$ points below the fitted line where it harms most. On
\texttt{node\_count}, which the summaries exclude, \texttt{qwen3-1.7b} answers
$39$ instead of $40$ on $68.5\%$ of items without a primer; \texttt{clustering}
removes this error almost entirely ($1.2\%$), whereas the longer \texttt{rwse}
leaves it ($66.5\%$; Appendix Table~\ref{tab:constgold}).

\section{Discussion and Conclusion}
\label{sec:discussion}

The results fit one account. A primer offers the model an alternative
procedure, and its effect is the accuracy of the procedure the model adopts
minus that of the one it abandons, weighted by how often it switches. Without
a primer the model has to count, so baseline accuracy measures the procedure a
primer can displace, which is why effects follow it. The account also explains
each arm. \texttt{qwen3-4b} substitutes retrieval for counting, which costs
accuracy where counting is reliable and gains where it fails;
\texttt{qwen3-1.7b-think} keeps counting and uses the primer as a check, which
gains without the loss; \texttt{qwen3-1.7b} rarely takes up the primer and
gains little even where its count fails. A switch pays only if the new
procedure can be executed: \texttt{qwen3-4b} completes the degree sum and
\texttt{qwen3-1.7b} does not, a failure of multi-step composition of the kind
\citet{dziri2023faithandfate} describe. And a primer that makes retrieval
harder, such as \texttt{all}, costs accuracy even where each of its parts
helps.

Two results bear on prior work. \texttt{node\_degree} and \texttt{edge\_count},
solvable by a single transformer layer \citep{sanford2024understanding}, are
where a stated answer helps and hurts most: for a prompted model the difficulty
is the procedure it runs, not the information it holds. And added text acts
through what it states --- a preamble restating the node set raises false
``yes'' answers, one concrete form of the distraction
\citet{shi2023distracted} report --- while length alone does not order the
effects \citep[cf.][]{levy2024sametask}.

In answer to our questions: a stated answer is worth about $16$ points at
intermediate baselines and side information $2$ to $4$ (RQ1); the sign follows
the accuracy of the procedure the primer displaces (RQ2); and a primer changes
that procedure, to retrieval, to verification or, on edge queries, to a
different rate of ``yes'' answers (RQ3). Evaluations of graph prompts should
report each cell's baseline accuracy, a graph-blind solver's score and, for
yes/no tasks, the false-alarm rate.

\section*{Limitations}
\label{sec:limitations}

We evaluate two model sizes from one family, with one encoding, template and
primer position. Decoding is greedy, whereas the Qwen3 model
card\footnote{\url{https://huggingface.co/Qwen/Qwen3-4B}} recommends
sampling in thinking mode, so the thinking arms' truncation on
\texttt{edge\_count} ($81\%$ and $62\%$) is specific to this protocol. In our
Erd\H{o}s--R\'enyi graphs local clustering varies little within a graph from
$p{=}.35$ on (standard deviation $0.05$ there and less beyond), which limits
what the \texttt{clustering} primer can convey. A
cell of $100$ graphs detects paired effects of about $8$ points, so the
side-information results rest on averages over cells. Procedures are
classified by surface patterns, and a model may follow a procedure it does not
state. The length comparison varies length only across primers whose content
also differs.

\section*{Ethics Statement}

This work evaluates open-weight models on synthetic graphs: no human subjects,
personal data or annotation, and no direct risk of harm we can identify. Its
main cost is GPU compute for about $217{,}000$ generations.%
