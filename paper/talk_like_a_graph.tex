\begin{abstract}
Prepending a \emph{primer} of factual sentences about a graph's structure
(node degree, clustering coefficient, random-walk return probabilities or
component count) to its text encoding is a natural way to assist a
language model on graph-reasoning questions. An apparent gain is
uninformative if the answer can be read from the primer without consulting
the graph, and confounded if the primer merely lengthens the prompt. We
evaluate primers against four controls jointly: a graph-blind shortcut
solver refit at the evaluated graph size, a length-matched content-free
filler, a minimal-length content control, and a degree-preserving rewiring
that varies triangle count at fixed prompt length. Across four Qwen3 arms
(1.7B and 4B, with and without thinking mode) on $40$-node
Erd\H{o}s--R\'enyi graphs, primers that state the answer help a model at
floor and harm a model at ceiling (cross-fitted interaction with baseline
accuracy $-11.0$ points, $95\%$ CI $[-17.1, -5.7]$), whereas primers that
do not state it show no such relation. The pattern replicates on eleven
held-out arms ($0.6$--$14$B, two families) but is not graded at
intermediate baselines. The only effect of a primer that does not state
the answer, \texttt{clustering} on \texttt{node\_degree}, is small when
pooled over densities ($+1.9$ points) and concentrated at intermediate
densities ($+5.9$, replicated on independent graphs); two candidate
mechanisms for it are not supported.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

\citet{fatemi2023talklikeagraph} show that a large language model's
accuracy on graph-reasoning questions varies substantially with the choice
of text encoding when the graph and question are held fixed. We ask a
complementary question about the same benchmark: does prepending a short
\emph{primer} of derived, node-level facts to the graph encoding improve
the model's answers?

Four confounds complicate the interpretation of such an effect. First, a
primer may help because the model reads the answer from it rather than
reasoning over the graph (answer leakage). Second, a primer changes prompt
length, and context length and position alone affect retrieval and
reasoning accuracy \citep{liu2024lostinthemiddle,kamradt2023needle,
levy2024sametask}. Third, answer extraction can err in ways that correlate
with response style, which appears as a spurious condition effect
(Section~\ref{sec:extraction}). Fourth, a model near ceiling on a task
leaves no room for any primer effect to appear.

We address three research questions. \textbf{RQ1}: when a primer improves
accuracy, is the improvement attributable to the primer stating the
answer? \textbf{RQ2}: does added text affect accuracy independently of its
content? \textbf{RQ3}: does any primer that does not state the answer
improve accuracy beyond a length-matched control, and through what
mechanism? Our main contribution is a set of controls applied jointly: a
graph-blind shortcut solver refit at the evaluated graph size
(Section~\ref{sec:shortcuts}), a length-matched content-free
\texttt{filler}, a minimal-length content control (\texttt{components}),
and a degree-preserving rewiring that changes triangle count at fixed
prompt length (Section~\ref{sec:rewiring}). We apply them to $40$-node
Erd\H{o}s--R\'enyi graphs across four model arms and six tasks.

\section{Related Work}
\label{sec:related-work}

We adopt the GraphQA task definitions of \citet{fatemi2023talklikeagraph}
and manipulate graph size and edge density directly, so that difficulty is
an experimental variable rather than an incidental one.
\citet{wang2023nlgraph} report that LLMs are brittle to spurious
correlations in graph problems and propose \emph{Build-a-Graph} and
\emph{Algorithmic} prompting, the prompt-level interventions closest to a
primer; \citet{perozzi2024letyourgraph} instead learn a continuous graph
encoding. \citet{guo2023gpt4graph} find that models struggle to exploit
graph description languages directly, and
\citet{jin2024largelanguagemodelsongraphs} survey the wider literature.
\citet{dziri2023faithandfate} argue that transformers solve compositional
tasks by linearised subgraph matching rather than systematic reasoning,
which raises the same question as a primer's benefit: does it reflect
reasoning or a shorter pattern to match? \citet{geirhos2020shortcut} frame
this as \emph{shortcut learning}; our shortcut solver operationalises that
concern for the primer channel. Irrelevant context degrades reasoning
\citep{shi2023distracted}, as does input length well below the context
limit \citep{levy2024sametask}; our \texttt{filler} condition measures this
cost directly. The \texttt{rwse} condition adapts the random-walk
structural encoding of \citet{dwivedi2022graph}, rendered as sentences, and
the rewiring follows the double-edge-swap configuration model
\citep{fosdick2018configuring}. For statistics we follow
\citet{dror2018hitchhikers} on paired testing, test differences between
groups directly rather than contrasting their significance
\citep{gelman2006difference}, and borrow cross-fitting from
\citet{chernozhukov2018double}. We distinguish Qwen3's native thinking mode,
toggled through the chat template, from chain-of-thought \emph{prompting}
\citep{wei2022chainofthought}; this paper tests only the former.

A primer is a preamble of factual sentences about a graph's structure,
prepended to the standard text encoding and the task question (Figure~\ref{fig:design}; a complete
example appears in Appendix~\ref{sec:appendix-prompt}). A single renderer
produces all seven conditions, so conditions share sentence framing and
number formatting and differ only in the facts stated. The exception is
\textbf{filler}, which states no fact and therefore uses its own frame
(``Node~$N$ is simply present within the graph G.''); it is a length
control, not a content control. \textbf{none} is the graph encoding alone.
\textbf{components} gives one sentence stating the number of connected
components. \textbf{degree} states each node's degree, \textbf{clustering}
each node's clustering coefficient, and \textbf{rwse} each node's
random-walk return probabilities after two and three steps
\citep{dwivedi2022graph}. \textbf{all} combines degree, clustering and rwse.
Mean primer length at $n{=}40$ (Qwen3 tokenizer) is $8$ tokens
(\texttt{components}), $372$ (\texttt{degree}), $470$ (\texttt{filler}),
$510$ (\texttt{clustering}), $1{,}070$ (\texttt{rwse}) and $1{,}612$
(\texttt{all}), against a mean \texttt{none} prompt of $2{,}165$ tokens.
\texttt{filler} is thus a close, slightly conservative length control for
\texttt{clustering}, but only bounds the length term for \texttt{rwse} and
\texttt{all}.

\subsection{Shortcut solvers}
\label{sec:shortcuts}

A primer's measured benefit is evidence of graph reasoning only if it
exceeds what a solver that never sees the graph can recover from the
primer text. Our shortcut solver combines sixteen exact rules, one
heuristic, eight fitted rules (fit and scored on disjoint graph sets) and an
exact enumeration bound for small graphs. Its accuracy on a (task,
condition) cell, the \emph{shortcut bar}, is a content-only lower bound: it
never overstates what the primer text alone permits.

A bar fit on the published $5$--$19$-node graphs does not transfer to our
$n{=}40$ corpus, so we refit the solver on $n{=}40$ Erd\H{o}s--R\'enyi
graphs at the seven densities of our sweep (disjoint $300$-graph fit and
test sets per density; Table~\ref{tab:shortcut}). We classify a (task,
condition) pair as offering a \emph{substitute route} when its bar exceeds
the \texttt{none} bar by more than $0.05$; every gain is either at most
$0.011$ or at least $0.066$, so any threshold between these values yields
the same split. Only \texttt{node\_degree} (under \texttt{rwse},
\texttt{degree}, \texttt{all}) and \texttt{edge\_count} (under
\texttt{clustering}, \texttt{degree}, \texttt{all}) offer a route.
\texttt{node\_count} and \texttt{cycle\_check} have constant gold answers at
$n{=}40$ ($40$, and ``yes'' at every density) and are excluded. The held-out
arms, which answer the published split, use bars fit on that split
(Appendix Table~\ref{tab:shortcut-published}).

\subsection{Rewiring: isolating structure from length}
\label{sec:rewiring}

\texttt{filler} controls length only approximately, and comparisons across
graph generators confound structure with class balance, so we use a
within-instance design. A double-edge swap replaces edges $(a,b),(c,d)$
with $(a,d),(c,b)$ \citep{fosdick2018configuring}, which preserves the
degree sequence, $n$, $m$, the \texttt{node\_degree} gold answer and the
prompt length while changing the triangle count that the
\texttt{clustering} primer reports. We generate \texttt{low},
\texttt{base} and \texttt{high} variants of each graph ($n{=}40$, mean
degree $12$, $200$ graphs per level; mean clustering $0.01$, $0.31$,
$0.73$) and evaluate \texttt{node\_degree} under \texttt{none},
\texttt{clustering} and \texttt{filler} with \texttt{qwen3-1.7b},
\texttt{qwen3-1.7b-think} and \texttt{qwen35-2b}. If the
\texttt{clustering} benefit derives from the stated values, it should vary
with triangle count. If instead the model reads mean clustering as a
density prior (in an Erd\H{o}s--R\'enyi graph $\bar{C}\approx p$), its
degree estimates should shift toward $\bar{C}\,(n-1)$: $0.5$, $12.0$ and
$28.7$ across levels, against a true mean of $12$.

\subsection{Answer extraction and measurement validity}
\label{sec:extraction}

Extraction errors can masquerade as condition effects. On
\texttt{cycle\_check}, \texttt{qwen3-4b} often answers correctly and then
recites that a cycle has ``no repeated'' nodes; a last-yes/no extractor
misread $225$ such rows, all in one direction, producing a spurious
collapse. All results use the corrected extractor, and a manual check of
$50$ rows per arm confirmed that \texttt{<think>} blocks never reach it.
Truncated pairs are dropped; scoring them as incorrect changes the verdict
on only three \texttt{qwen3-1.7b} \texttt{cycle\_check} cells
(Appendix~\ref{sec:appendix}).

\subsection{Significance testing}
\label{sec:significance}

Every comparison is paired on the same graph and question and tested with
the exact McNemar test \citep{mcnemar1947note}, Benjamini--Hochberg
corrected \citep{benjaminihochberg1995controlling} within each (arm, task)
family at $q{=}0.05$; a claim that a condition beats both controls also
requires significance under a global correction. For the effect--baseline
relation (Section~\ref{sec:results-baseline}), baseline and effect are
estimated from disjoint random halves of each cell's graphs, and the route
$\times$ baseline interaction is bootstrapped over (arm, task, density)
blocks, which share one \texttt{none} sample. For null cells we simulate a
minimum detectable effect (MDE) at power $0.8$, $\alpha{=}0.05$.

\section{Experimental Setup}
\label{sec:setup}

\paragraph{Tasks.} Six GraphQA tasks \citep{fatemi2023talklikeagraph}: node
count, edge count, node degree, connected nodes, edge existence and cycle
check.

\paragraph{Models.} An \emph{arm} is a model checkpoint with a fixed
decoding configuration. The main arms are Qwen3-1.7B and Qwen3-4B
\citep{qwen2025qwen3}, each with native thinking mode off
(\texttt{qwen3-1.7b}, \texttt{qwen3-4b}) and on (\texttt{-think}), chosen
because they offer both modes of the same weights at two sizes and
moderate cost.

\paragraph{Sweep design.} All four arms answer one shared prompt set:
Erd\H{o}s--R\'enyi graphs \citep{erdosrenyi1959random} with $n{=}40$ at
densities $p\in\{.10,.20,.35,.50\}$, $100$ graphs per (density, task) cell,
seven conditions and six tasks, for $16{,}800$ prompts per arm. Decoding is
greedy with a budget of $2{,}048$ new tokens for plain arms and $8{,}192$
for thinking arms; Section~\ref{sec:results-thinking} reports a
budget-matched comparison. A high-density extension covers
\texttt{node\_degree} and \texttt{edge\_existence} at $p\in\{.65,.75,.85\}$
($100$ graphs per cell, all four arms). For the one content effect that
survives the controls (Section~\ref{sec:results-clustering}), a dedicated
\texttt{node\_degree} sweep with \texttt{qwen3-1.7b} uses $400$ graphs per
density at all seven densities, and a replication uses $400$ newly seeded
graphs per density at $p\le.50$.

\paragraph{Held-out arms.} Eleven further arms were not used to develop any
claim reported here. Eight (Qwen3-8B, Qwen3-14B, Gemma-4-E4B-it and
Gemma-4-12B-it \citep{gemma4}, each with and without thinking) answer the
published GraphQA split ($30$ graphs per cell, five tasks, six conditions);
three (Qwen3-0.6B with and without thinking, and Qwen3.5-2B
\citep{qwen35}, \texttt{qwen35-2b}) answer a $100$-graph probe of
\texttt{none} and \texttt{degree} on all six tasks. The published-split
responses were collected before this project's hypotheses were formed, so
we describe these arms as held out rather than pre-registered.

\paragraph{Metrics.} Exact match for every task (set-F1 on
\texttt{connected\_nodes} is $0.96$--$1.00$ in every cell and does not
discriminate); mean absolute error for the integer tasks is in the
Appendix.

\section{Results}
\label{sec:results}

\subsection{Main sweep}
\label{sec:results-main}

\input{main_table.tex}

Unless stated otherwise, $\Delta$ is a paired difference against
\texttt{none}, in percentage points, over instances in which neither
condition was truncated. Table~\ref{tab:main-results-plain} (thinking arms
in Table~\ref{tab:main-think}) pools over the four densities; per-cell
bootstrap intervals are in the Appendix. On \texttt{edge\_count} the
thinking arms truncate on $62$--$81\%$ of instances (Appendix
Table~\ref{tab:hitcap}), so those cells are reported but not interpreted;
every other task truncates on fewer than $7\%$. Gains on the
constant-answer tasks \texttt{node\_count} and \texttt{cycle\_check} are
artifacts (Section~\ref{sec:results-length}). Several cells are significant
in one arm but not the other; Section~\ref{sec:results-baseline} shows why
this is expected, since the two model sizes are rarely at matched baseline
accuracy on the same cell.

\subsection{Length is an active treatment}
\label{sec:results-length}

\texttt{filler} is not inert. It significantly reduces accuracy for
\texttt{qwen3-1.7b} on \texttt{edge\_existence} ($-15.8$) and
\texttt{connected\_nodes} ($-6.2$), and for \texttt{qwen3-4b} on both
($-7.0$, $-12.5$). Over the full seven-density range
(\texttt{qwen3-1.7b-think}, \texttt{node\_degree}) it costs $6.3$ points
pooled ($p{<}10^{-4}$): negligibly at $p{\le}.35$, then $9.5$, $9.3$, $14.1$
and $11.7$ points at the four densest levels ($r{=}{+0.953}$ with
baseline across levels, $p{=}0.00088$). The cost of added length thus grows
with task difficulty, in the same direction as the benefit of an
answer-stating primer (Section~\ref{sec:results-baseline}).

The largest \texttt{edge\_existence} effects are not changes in graph
reading: the hit rate is $99$--$100\%$ under every condition, so accuracy
moves only through the false-alarm rate, which \texttt{filler} raises and
\texttt{clustering} lowers (Appendix Table~\ref{tab:booleanbias}). With hits
at ceiling, a signal-detection analysis \citep{macmillan2005detection,
hautus1995corrections} cannot separate sensitivity from criterion
(Appendix Table~\ref{tab:sdt}). On \texttt{node\_count} (gold $=40$), the
dominant \texttt{none} error is an off-by-one (``$39$'', induced by the
encoder's ``nodes $0,\dots,39$'' preamble; $68.5\%$ of \texttt{qwen3-1.7b}
answers), which almost any interposed text reduces.

\subsection{Answer-stating primers: route substitution}
\label{sec:results-baseline}

per density, $95\%$ bootstrap intervals). Lower tick row: accuracy under

A \emph{cell} is an (arm, task, density, condition) combination with at
least ten usable pairs. On the main sweep plus the high-density extension,
route cells gain at low baseline and lose at high baseline, while no-route
cells do not (Figure~\ref{fig:crossfit}; binned means in Appendix
Table~\ref{tab:baseline}). Because baseline and effect share sampling noise,
and a difference in significance is not a significant difference
\citep{gelman2006difference}, we test the cross-fitted route $\times$
baseline interaction directly: $-11.0$ points per unit of baseline ($95\%$
block-bootstrap CI $[-17.1, -5.7]$, $83$ blocks; within groups $r{=}{-0.34}$
for $116$ route cells and $r{=}{+0.03}$ for $381$ no-route cells). The
interaction persists on the logit scale, which removes the compression of a
bounded outcome ($-1.46$ logits, CI $[-2.11, -0.79]$), but vanishes among
cells with baseline between $0.10$ and $0.90$ (interaction CI $[-29,
+41]$; Appendix Table~\ref{tab:robust}). The evidence thus supports a
contrast between floor and ceiling (a stated answer helps a model that
cannot compute it and harms one that already can) rather than a graded
dependence at intermediate baselines, where our data are sparsest.
Manipulating difficulty directly gives the same picture
(Figure~\ref{fig:continuum}): for \texttt{qwen3-1.7b-think} on
\texttt{node\_degree}, raising density from $p{=}.10$ to $.85$ lowers
\texttt{none} accuracy from $0.95$ to $0.44$ while \texttt{degree}'s
benefit rises from $+3.1$ to $+34.2$ points ($r{=}{-0.975}$).

\paragraph{Held-out arms and renaming.}
\label{sec:results-heldout}
On the eleven held-out arms the interaction replicates ($-24.7$, CI $[-109,
-3.8]$, $43$ (arm, task) blocks; route $r{=}{-0.674}$ over $105$ cells,
no-route $r{=}{-0.186}$ over $93$). Replacing each cell's own baseline with
the other arms' accuracy on the same cell removes the relation
($r{=}{+0.113}$, $p{=}0.135$), so the effect tracks a model's own competence
rather than item difficulty. Replacing integer node identifiers with
Game-of-Thrones names leaves \texttt{degree}'s effect intact ($r{=}0.933$
between the two sweeps over $39$ cells), so the effect does not depend on
integer labels; it cannot distinguish copying the stated value from
computing the answer. When the model errs despite a stated answer, the
error is often a neighbour's value: $12$ of \texttt{qwen3-4b}'s $29$
\texttt{degree} errors on \texttt{node\_degree} equal the stated degree of
the adjacent node in the list ($17.3\%$ expected by chance, $p{=}.002$).

\subsection{Non-answer content: clustering on node\_degree}
\label{sec:results-clustering}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{headline.pdf}
\caption{\texttt{clustering} and \texttt{filler} against \texttt{none} on
\texttt{node\_degree}, \texttt{qwen3-1.7b}, by density ($400$ graphs per
density, $95\%$ bootstrap intervals). Pooled comparisons: Appendix
Table~\ref{tab:headline}.}
\label{fig:headline}
\end{figure}

\texttt{clustering} on \texttt{node\_degree} is the only cell in which a
primer that does not state the answer was followed up; it was selected
after the main sweep and re-run with $400$ graphs per density and an
independent-seed replication (Figure~\ref{fig:headline}; Appendix
Tables~\ref{tab:headline} and~\ref{tab:headline-density}). Pooled over
seven densities, the gain over \texttt{none} is small ($+1.9$ points,
$p{=}0.022$; replication at $p{\le}.50$: $+4.2$, $p{=}0.00055$). The larger
pooled gain over \texttt{filler} ($+4.3$) mostly reflects \texttt{filler}'s
own cost, which accounts for the whole difference at $p{\ge}.65$.
Against both controls, the effect is concentrated at intermediate
densities: pooled over $p{=}.35$ and $.50$, \texttt{clustering} exceeds
\texttt{none} by $+5.9$ points ($95\%$ CI $[2.1, 9.8]$, $p{=}0.0036$) and
\texttt{filler} by $+6.4$ ($[2.8, 10.0]$, $p{=}0.0012$), while
\texttt{filler} and \texttt{none} do not differ ($-0.5$), so length does
not account for it. This range was identified from the dedicated sweep;
the independent-seed replication, which played no part in choosing it,
gives $+5.5$ against \texttt{none} over the same two densities ($[1.5,
9.5]$, $p{=}0.0083$). Per-density estimates are too imprecise to localise
the effect more finely. \texttt{qwen3-4b}, at ceiling in the main sweep, shows the effect on the
high-density extension ($+11.3$ against \texttt{none}, $+9.3$ against
\texttt{filler}, both significant under the global correction); the
thinking arms do not.

Neither mechanism we can test explains the effect (Appendix
Figure~\ref{fig:rewiring}). Under rewiring, mean clustering rises from
$0.01$ to $0.73$ but the benefit does not follow (\texttt{qwen3-1.7b}:
$+3.5$, $+6.0$, $+2.5$ across levels), and for \texttt{qwen35-2b}
\texttt{filler} matches or exceeds \texttt{clustering} at every level. The
density-prior prediction fails too: signed error under \texttt{clustering}
should shift by up to $17$ at \texttt{high}, but the paired shift is within
$0.3$ of zero at every level for all three arms (Appendix
Table~\ref{tab:prior}).

\subsection{Thinking mode and power}
\label{sec:results-thinking}
\label{sec:results-power}

Thinking brings most cells to ceiling, and where it does not, truncation
censors the task. Rescoring the thinking arms at the plain arms'
$2{,}048$-token budget (exact under greedy decoding) shows that part of
thinking's advantage is budget: it still wins on \texttt{edge\_existence}
($97.8$ vs.\ $70.5\%$ for 1.7B) but loses on \texttt{cycle\_check} ($38.0$
vs.\ $90.7\%$), and no \texttt{edge\_count} trace finishes (Appendix
Table~\ref{tab:budget}). Many main-sweep nulls are uninformative: in $10$
of $24$ null cells for \texttt{qwen3-1.7b}, $10/20$ for \texttt{qwen3-4b},
$23/33$ and $33/33$ for the thinking arms, an effect in at least one
direction is undetectable at any size because \texttt{none} accuracy is at
floor or ceiling; elsewhere the median MDE for a gain is $5.6$ (1.7B) and
$10.0$ points (4B).

\section{Conclusion}
\label{sec:conclusion}

Structural primers change LLM accuracy on GraphQA in two ways. For RQ1, a
primer that states the requested quantity acts as a second route to the
answer, helping a model at floor and harming one at ceiling; the contrast
survives cross-fitting, a logit transformation, held-out arms, a
negative-control difficulty estimate and node renaming, but is not graded
at intermediate baselines. For RQ2, added text is an active treatment whose
cost exceeds most content effects and grows with difficulty, so a primer
compared only against \texttt{none} confounds content with length. For
RQ3, the one surviving effect of non-answer content is small, concentrated
at intermediate densities and unexplained. All claims are behavioural.
Evaluations of prompt-level graph augmentations should report baseline
accuracy, a length-matched control and a graph-blind solver.

\section*{Limitations}
\label{sec:limitations}

The main sweep covers two model sizes from one family; the held-out arms
extend the range but on a smaller corpus with fewer conditions and were not
pre-registered. The route classification depends on a threshold and on the
$n{=}40$ shortcut refit, and the route relation is not detectable within
the $0.10$--$0.90$ baseline window, where data are sparse. All graphs are
Erd\H{o}s--R\'enyi, in which local clustering is nearly uniform, so the
\texttt{clustering} primer carries little node-specific information; the
rewiring varies triangle count within this family but does not test other
families. The length control matches \texttt{clustering} to within $8\%$ in
tokens but is much shorter than \texttt{rwse} and \texttt{all}. Every prompt
uses one encoding (\texttt{incident}), one template and one primer
position, with greedy decoding. The \texttt{clustering} cell was selected
after the main sweep, and several results rest on $400$ or fewer instances
per cell; an MDE is reported for every null result, but it does not replace
a larger sample. Three primers would address the main open questions: a
\emph{shuffled-value} primer (same values, permuted across nodes) as a
stricter placebo than \texttt{filler}, a \emph{corrupted} primer stating
wrong degrees to separate copying from computation, and a
\emph{single-fact} primer to separate interference from route
substitution.

\section*{Ethics Statement}

This work evaluates open-weight language models on synthetically generated
Erd\H{o}s--R\'enyi graphs. It involves no human subjects, no personal or
identifying data and no annotation labour. We see no direct risk of harm
from the findings; the principal cost is the GPU compute for approximately
$200{,}000$ generations.
