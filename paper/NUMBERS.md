# Number -> script source map

Every hand-typed number in `talk_like_a_graph.tex`'s prose (not the tables
generated by `\input`, which are self-evidently sourced from the script
that wrote them) traces to one of these commands. Run `bash
paper/make_all.sh` to regenerate everything at once; the per-command notes
below are for auditing one number at a time.

Tables `\input{main_table.tex}` and `\input{ci_table.tex}` are written by
`paper/make_main_table.py` and `paper/make_ci_table.py` respectively --
every number in Tables 3, 4, and 8-11 comes from those, not from this file.

## Section 3.2 (shortcut bars, Table 1)

- Published-split bars (top half of Table 1): `scripts/shortcut_table.py --graphs 500`
- n=40 refit, per-density (bottom half, mean over 7 densities):
  `scripts/shortcut_table_n40.py --json shortcuts_n40.json --flat-json shortcuts_n40_flat.json`
- "edge_existence/none bar 0.498 -> 0.735", "degree-over-none gap 0.296 -> 0.011":
  read directly off shortcuts.json vs shortcuts_n40_flat.json (`edge_existence/none`,
  `edge_existence/degree`).

## Section 3.4 (extraction bug)

- "225 of qwen3-4b's scored boolean rows": one-time historical fix, `b88abfd`
  (cycle_check "no repeated" extraction fix); not re-derivable from current
  runs since it describes a diff between two extractor versions. Verified
  once via `scripts/audit_extraction.py`'s classify() ground-truth check.
- "<think> tags never reach the extractor unstripped": `scripts/audit_extraction.py`

## Section 5.1 (Table 2, truncation)

- All cells: computed directly from `runs/{arm}.densfull40.shard*of25.jsonl`'s
  `hit_cap` field, pooled over condition and density per (arm, task). See the
  loop in `paper/make_main_table.py`'s `load()` / `cell()` for the same logic.

  `scripts/analyze_baseline_law.py --test continuum`

  `scripts/candidates/h_got.py`
