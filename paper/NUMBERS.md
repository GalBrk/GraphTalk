# Number -> script source map

Every hand-typed number in the paper's prose (not the tables generated by
`\input`, which are self-evidently sourced from the script that wrote them)
traces to one of these commands.

## v3 (current paper)

Every number in the body of `talk_like_a_graph.v3.tex` traces to a column of
`csv2/raw-trends/`, which is rebuilt from the raw generations by:

```bash
PYTHONPATH=. python scripts/build_raw_frame.py            # runs/ -> frame.csv
PYTHONPATH=. python scripts/raw_trends.py --question all  # -> the rest
PYTHONPATH=. python scripts/analyze_primer_window.py --tex paper/v3_window_table.tex
```

`build_raw_frame.py` regenerates every graph from its `instance_id` and aborts
if a regenerated gold answer disagrees with the stored one, so a clean run is
also a check that the frame matches the generations.

  Row 1 (+3.0, p=0.26): `ci_all.json` `qwen3-1.7b|node_degree|clustering` `p_mcnemar`.

  counts: `mde_qwen3-*.csv`, null rows (`bh_significant == False`), a cell counted when
  either `mde_note` or `mde_note_negative` is set.
  The 24 `connected_nodes` rows across those four files (and the 48 in
  `densfull40_tests.csv`, which covers both controls) were recomputed 2026-09-22
  and folded back in; every other row is untouched. Two fixes made that necessary:
  `minimum_detectable_effect_clustered` now refuses a non-binary outcome instead of
  bisecting to its floor, and `mde_for_arms` binarizes at `>= 0.9999` first --
  `connected_nodes` is the only set-F1 task here, and feeding graded F1 to a
  Bernoulli injector is what produced the superseded 5.6/10.0. Regenerate with
  `scripts/score_full_density_sweep.py --responses "runs/<arm>.densfull40.shard*of25.jsonl"
  --shortcuts shortcuts.json --tasks connected_nodes --control {none,filler} --mde --csv <out>`.
  The **counts were unchanged** by the fix; only the medians moved, and only via those
  six rows per arm (for `qwen3-4b` they were 10.0-13.1pp and are now 4.8-8.1pp, which
  is what took the median from 10.0 to 5.4). Pre-fold copies: `archive/pre-mde-fold/`.
