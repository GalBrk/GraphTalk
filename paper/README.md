# Paper

There is no current paper source here yet. This directory holds what the next
one needs:

- `acl2023.sty`, `acl.sty`, `acl_natbib.bst`: the ACL style files.
- `custom.bib`: the bibliography.

**Results to write it from** live in [`docs/results/`](../docs/results/README.md):
one document per family of runs, each stating only what its script's committed
output shows. The main experiment is the 40-node sweep,
[`docs/results/n40-sweep.md`](../docs/results/n40-sweep.md).

**Earlier drafts** (v1, v2, v3, the short draft, the independent reanalysis, the
synthesis draft and two drafts built outside the repo) are in
[`superseded/paper/`](../superseded/paper/); none of them is current.
[`superseded/paper/CLAIMS_LEDGER.md`](../superseded/paper/CLAIMS_LEDGER.md)
records where and why they disagreed.
