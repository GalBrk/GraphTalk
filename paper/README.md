# Building the paper

**`talk_like_a_graph.v3.tex` is the current paper** — ACL 2023 format
(`acl2023.sty`), a 5-page body with Limitations and Ethics also inside page 5,
then references and a short appendix, built by `bash paper/make_v3.sh`. Jump
to "The v3 build" below.

Two earlier sources are still in this directory and still build:

| Source | Status | Build |
|---|---|---|
| `talk_like_a_graph.v3.tex` | **current** | `bash paper/make_v3.sh` |
| `talk_like_a_graph.v2.tex` | frozen — the version under advisement, kept so its PDF can be reproduced | by hand: `latexmk -pdf talk_like_a_graph.v2.tex`, after `paper/short/make_v2_tables.py` |
| `talk_like_a_graph.tex` | superseded | `bash paper/make_all.sh` |

v3 keeps v2's controls apparatus — the shortcut solvers, the length-matched
`filler`, the rewiring — and rebuilds the results on the 40-node sweep read
back from raw `runs/` by `scripts/build_raw_frame.py`. Do not edit `v2.tex`;
it exists to reproduce a PDF someone else is holding.

## The v3 build

```bash
bash paper/make_v3.sh
```

Runs `scripts/primer_findings.py --figure-data` (the float CSVs), then
`paper/make_v3_tables.py` (the `v3_*_table.tex` floats) and
`paper/make_v3_figures.py` (`v3_fig_window.pdf`, `v3_fig_edgeexist.pdf`), then
`latexmk`. It ends with a page gate: the Limitations heading and the end of the
Ethics statement must both land on page 5 or earlier.

It deliberately does **not** run `make_all.sh`; nothing v3 uses needs its
~20-minute `ci_all.py` leg. The older `v3_fig_*.pdf` figures and
`v3_*_table.tex` files that the current `.tex` no longer inputs stay on disk
only so earlier revisions still build.

Everything under `csv2/raw-trends/` is regenerated by:

```bash
PYTHONPATH=. python scripts/build_raw_frame.py     # runs/ -> frame.csv
PYTHONPATH=. python scripts/raw_trends.py --question all
```

`build_raw_frame.py` re-derives every graph from its `instance_id` and aborts
if any regenerated gold answer disagrees with the one stored in `runs/`, so a
successful run is also a check that the frame matches the generations.

## The v1 build (superseded)

```bash
bash paper/make_all.sh
```

Runs every analysis script that feeds the paper, in dependency order, then
`paper/make_main_table.py` / `make_ci_table.py` / `make_tables.py` /
`make_figure*.py` to regenerate the `\input`-ed tables (`main_table.tex`,
`ci_table.tex`, `appendix_tables.tex`) and figures (`effects.pdf`,
`crossfit.pdf`, `rewiring.pdf`, `density.pdf`), then
`latexmk -pdf` to build `talk_like_a_graph.pdf`. Read the script itself for
which analysis feeds which section — each step is labelled with the section
number it covers. Takes roughly 20 minutes, dominated by `ci_all.py`.

## Just the PDF

If the tables and figures are already up to date and only the prose changed:

```bash
cd paper && latexmk -pdf -interaction=nonstopmode talk_like_a_graph.v3.tex
```

## Checking a specific number

`NUMBERS.md` maps every hand-typed number in the prose (not the numbers inside
`\input`-ed tables, which are self-evidently sourced from the script that
wrote them) to the exact command that produces it. Use it to audit one claim
without rerunning a full build.

## Not part of the build

`headline.pdf` and `continuum.pdf` are stale: `make_figure_density.py` now
emits the two of them as one stacked figure, `effects.pdf`. The old files
are left on disk only so an older revision of the `.tex` still builds.

`density.pdf` and `appendix_tables.tex` are built by `make_all.sh` but not
`\includegraphics`/`\input` anywhere in the current `.tex` — kept because a
future extension of the paper may want them (see `docs/paper-revision-handoff.md`'s
"What is NOT in the final paper" note for why they were cut and what they'd
support).
